# 窗口语义（Window Semantics）

本文件是窗口计算结果的权威定义。任何两次相同输入的查询都必须产生逐字节一致的输出。

## 1. 分区与排序

* 输入行属于一个**分区键**（字符串）。
* 查询固定在单个分区内进行，分区之间互不影响。
* 分区内的排序键为：

  ```
  (sort_key, seq)
  ```

  * `sort_key`：用户提供的排序键，允许整数、浮点数、字符串或 `NULL`。
  * `seq`：行被提交到存储时分配的全局自增序号。它是排序键相等时的**最终且唯一**的决胜键，保证同一提交顺序下排序稳定、确定。

* 数值按数值大小比较（整数与浮点数互不损失精度地混排）。若一个分区内同时出现数值与字符串键，遵循 SQLite 的存储类排序规则：数值排在字符串之前；空字符串排在其他字符串之前。混合数值/字符串类型仅用于排序，不会用于聚合运算。
* 排序键不支持布尔、对象、数组等其它类型（写入时返回 `400`）。

### 1.1 NULL 排序键

* 由查询参数 `null_order` 决定，取值：
  * `nulls_last`（默认）：所有非 NULL 键在前，所有 NULL 键在最后；
  * `nulls_first`：所有 NULL 键在最前。
* **所有 NULL 排序键构成一个并列组**：在排名函数中它们共享同一名次，且彼此按 `seq` 稳定排序。
* NULL 排序键与“值（value）为 NULL”是两个独立概念：排序键为 NULL 不影响其 value 参与聚合。

## 2. 窗口范围（Frame）

每个聚合函数必须声明一个窗口；排名函数与 LAG/LEAD 不接受窗口。

| Frame | 含义 | 第 `i` 行（0 基）的窗口 |
|---|---|---|
| `partition` | 分区内全部行 | `[0, N)` |
| `rows_preceding` | 当前行及其之前 `n` 行 | `[max(0, i-n), i]` |
| `rows_around` | 当前行前后各 `n` 行 | `[max(0, i-n), min(N-1, i+n)]` |

### 2.1 边界行为（确定且已定义）

* `rows_preceding` / `rows_around` 在分区起始/结束处**裁剪（clip）**到实际存在的行，不进行循环、也不用虚拟行填充。
* `n = 0` 时：
  * `rows_preceding n=0` 与 `rows_around n=0` 都等价于“仅当前行”。
* 窗口始终基于**物理行位置**（ROWS 语义），不是值区间（RANGE）。因此相同排序键的多个行仍占据各自不同的位置。

## 3. 计算函数

### 3.1 排名类

设排序后行号（1 基）为 `pos`，`run_start` 为当前并列组首行的 0 基位置，`distinct` 为到当前行为止出现过的不同键个数。

| 函数 | 结果 |
|---|---|
| `row_number` | `pos`（并列键也占不同行号，由 `seq` 决定先后） |
| `rank` | `run_start + 1`（并列同名次，之后**跳号**） |
| `dense_rank` | `distinct`（并列同名次，之后**不跳号**） |

例：键 `1,1,2,3,3,4` 的 rank 为 `1,1,3,4,4,6`，dense_rank 为 `1,1,2,3,3,4`。

### 3.2 前后项取值类（LAG / LEAD）

* `lag(offset=k)`：取当前行之前第 `k` 行的 **value**。
* `lead(offset=k)`：取当前行之后第 `k` 行的 **value**。
* 关键区分（两种“缺失”不是一回事）：
  * 被引用的**行不存在**（越过分区边界）：返回函数的 `default`；
  * 被引用的**行存在但其 value 为 NULL**：返回 `NULL`，而不是 `default`。
* `offset` 必须 `>= 1`，默认 1。

### 3.3 滑动聚合类

聚合读取每行的 `value`，`value` 允许整数、浮点数、字符串或 NULL。

| 函数 | 规则 |
|---|---|
| `sum` | 非 NULL 值之和；帧内没有非 NULL 值（空帧或全 NULL）时返回 `NULL` |
| `count` | 非 NULL 值的个数；空/全 NULL 帧为 `0` |
| `avg` | `sum / 非 NULL 个数`；没有非 NULL 值时返回 `NULL`，结果总是浮点数 |
| `min` | 非 NULL 值的最小值；全 NULL/空帧为 `NULL` |
| `max` | 非 NULL 值的最大值；全 NULL/空帧为 `NULL` |

* 除 COUNT 与“全空帧的 SUM”外，NULL 输入一律被忽略。
* SUM 在全部输入为整数时保持整数累加，混入浮点数后变为浮点。
* MIN/MAX 要求被比较值类型可比较（数值之间或字符串之间）。

## 4. 确定性保证

1. 排序由 `(sort_key, seq)` 唯一确定，`seq` 单调反映提交顺序；
2. 聚合与排名均为顺序无关之外的纯函数，SUM/COUNT/AVG 用精确累加；
3. 结果按 `row_index` 顺序持久化，GET 接口按该顺序分页返回；
4. 因此，对相同的（有序）输入批次集合，任意两次查询输出完全一致，包括并列键的行序与 NULL 位置。
